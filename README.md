# Design-of-a-Simple-General-Purpose-Processor
The purpose of this lab was to design a General Processing Unit (GPU) in VHDL using an Arithmetic and Logic Unit (ALU), a 4:16 decoder, two latches, and a Final State Machine (FSM). The two latches act as storage units as they store the last 4 digits of the student number (A and B) that will be outputted to the ALU. They are dependent on the rising edge of the clock and can be reset at the user’s discretion. The latch output will be fed into the ALU, which will perform the logic using the A and B values defined for each microcode. This microcode instruction comes from the 4:16 decoder. The FSM is responsible for controlling which microcode the decoder sends to the ALU as it is dependent on the current state of the system.  Together, the decoder and FSM act as a control unit. The intersectionality and function of the components will further be discussed in the Components section.  It must be noted that a block diagram will utilize all components described above in order for an output to be displayed on an FPGA board.
